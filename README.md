# Pacman-Game
This a small Pac-Man style game built in C++ using the Raylib framework. I created it as a learning project to get comfortable with C++ fundamentals and basic rendering. It is playable to a certain extent though still unfinished and contains a few known bugs.

Features
- Classic Pac-Man movement and grid-based navigation
- Basic scoring + power-up logic
- Collectible pellets
- Raylib-based rendering and input
- Basic collision detection

What I learned
- Structuring a simple game loop in C++
- Using Raylib for rendering, textures and input
- Managing game state and entity movemnet
- Handling grid-based collision logic

Tech Stack
- Languages: C++
- Framework: Raylib
- Build System: Visual Studio

How To Run
- Install Raylib 
- Clone the Repository
- Build using your preferred compiler
- Run the executable
